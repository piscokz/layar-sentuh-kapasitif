# Layar Sentuh Smartphone (*Capacitive Touchscreen*) — Topik 5

Media pembelajaran interaktif bertahap untuk **Diskusi Fisika Dasar: Gaya Coulomb dan Medan Listrik (Topik 5 — Layar Sentuh Smartphone)**.

🌐 **Tautan GitHub Pages**: https://piscokz.github.io/layar-sentuh-kapasitif/

## Struktur 7 Tahap Pembelajaran

1. **Tahap 1 — Identifikasi Fenomena**: Mengapa layar sentuh kapasitif mendeteksi sentuhan ringan tanpa tekanan mekanis dibandingkan layar resistif.
2. **Tahap 2 — Anatomi Layar Sentuh**: Eksplorasi interaktif 5 lapisan layar (*Cover Glass*, Elektroda Rx ITO, Isolator Dielektrik, Elektroda Tx ITO, dan Panel Display).
3. **Tahap 3 — Muatan Listrik, Gaya Coulomb, & Medan Listrik Tepi (*Fringing Field*)**: Simulasi `<canvas>` interaktif distribusi muatan dan pembelokan garis medan listrik saat jari mendekat.
4. **Tahap 4 — Bagaimana Sentuhan Mengubah Kapasitansi?**: Perbandingan *Mutual Capacitance* (standar *multi-touch* modern) dan *Self Capacitance*.
5. **Tahap 5 — Lab Simulasi Virtual Kisi Sensor 6×8**: Pengujian sentuhan jari telanjang, sarung tangan kain, sarung tangan konduktif, stylus plastik, stylus kapasitif, tetesan air, dan mode *Multi-Touch*.
6. **Tahap 6 — Mengapa Sarung Tangan Biasa Gagal? & Aplikasi Modern**: Analisis sifat isolator, jarak $d$, serta penerapan kapasitansi di perangkat modern.
7. **Tahap 7 — Rangkuman Diskusi, Pertanyaan Tantangan, & Kuis**: Jawaban 4 pertanyaan panduan Topik 5, 4 pilar Analisis Konsep Fisika, pembuktian polarisasi muatan pada benda netral, dan mini kuis 4 soal.

## Fitur Utama

- **Dua Mode Membaca**: Mode gulir berurutan (Tahap 1–7) dengan indikator progres baca serta **Mode Fokus (1 Tahap)** dengan navigasi Sebelumnya/Berikutnya.
- **Adaptif Tema & Aksesibilitas**: Mendukung tema terang/gelap otomatis (`light-dark()` dengan fallback `prefers-color-scheme`), *Forced Colors Mode*, navigasi keyboard penuh, dan *live region* pembaca layar.
- **Tanpa Build Step**: Dibangun murni dengan HTML5 semantik, CSS modern, dan JavaScript vanilla (`index.html`, `styles.css`, `app.js`).
